const update = (model: Model, message: Message):

Why Orikit

Behavior belongs to one Program. Platforms just render it.

Cross-platform frameworks usually share the UI and fork the logic. Orikit does the opposite: your entire application behavior lives in one typed, pure core, and each platform gets the view layer it deserves.

Pure logic, shared

Model, Message, update, Commands, Subscriptions — the whole behavior of your app is one pure TypeScript Program. It has no idea whether it's running in a browser or on a phone.

Real native views

NativeScript renders actual EditText, virtualized ListView, native buttons. Platform-familiar controls, platform accessibility — not browser widgets in a costume.

Deterministic by design

Story tests, canonical traces, effect-free replay, time travel. When something breaks, you don't reproduce it by clicking around — you replay exactly what happened.

Architecture

One update function. Two platforms. Zero divergence.

The Program owns state transitions; each platform contributes only a view. The Todo slice below ships in the repository — the same update function serves both views, and both runs produce identical traces.

// shared — packages/core
const update = (model, message) => {
  switch (message.kind) {
    case 'TodoAdded':
      return [add(model, message.title), [persist]]
    case 'TodoToggled':
      return [toggle(model, message.id), [persist]]
    case 'TodoDeleted':
      return [remove(model, message.id), [persist]]
    case 'LoadFailed':
      return [failed(model), [report]]
  }
}
// web view — foldkit
const view = (model) =>
  section([], [
    input([onInput(DraftChanged), value(model.draft)]),
    button([onClick(TodoAdded)], [text('Add')]),
    todoList(model.todos),
  ])
// native view — nativescript
const view = (model) =>
  stackLayout([], [
    textField([onTextChange(DraftChanged), text(model.draft)]),
    nativeButton([onTap(TodoAdded)], 'Add'),
    listView(model.todos, todoItem),
  ])

Load, add, edit, toggle, delete, failure, retry — one set of semantics, verified on both platforms.

Built for the AI era

Legible to agents, not just to you.

Every state change is a typed Message. Every run is a replayable trace. Orikit exposes the same logical runtime to developers and AI agents — through a remote web inspector and an MCP bridge — so your tools can read the application the way you do.

  • mcp bridge — agents inspect the live runtime
  • typed messages — every interaction traces to one
  • canonical traces — byte-stable, diffable runs
  • time travel — effect-free replay of any session
