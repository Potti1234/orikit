# OriKit documentation

The active implementation plan is the NativeScript-first design in
[`nativescript/`](nativescript/README.md).

Start here:

1. [`nativescript/01-product-definition.md`](nativescript/01-product-definition.md)
   defines the product and its boundaries.
2. [`nativescript/10-implementation-roadmap.md`](nativescript/10-implementation-roadmap.md)
   gives the phased implementation order.
3. [`nativescript/13-agent-runbook.md`](nativescript/13-agent-runbook.md) tells an
   implementation agent how to work through the plan.
4. [`nativescript/14-windows-android-setup.md`](nativescript/14-windows-android-setup.md)
   contains the concrete setup and physical-device workflow for the current
   Windows machine.
5. [`nativescript/17-feasibility-spike.md`](nativescript/17-feasibility-spike.md)
   defines the first experiment and its pass/fail gates.

The other numbered documents in this directory describe the earlier
Kotlin Multiplatform compiler approach. They are retained as research and as a
fallback option, but they are not the authoritative implementation plan.
